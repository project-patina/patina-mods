# Patina mods

Official mods for the Patina Rust client, shown in the launcher's "Patina mods" tab.

`index.json` lists the mods and `index.json.sig` is its signature. The launcher reads the list only if the signature verifies against the key built into it, and installs a file only if its SHA-256 matches the list. Mod files are attached to this repository's releases.
